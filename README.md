# Portfolio sites

Sample websites designed and engineered by Thakshila Wijerathne. Each folder is a self-contained static site: open its `index.html` in a browser, no build step.

The businesses in these samples are fictional. Names, contact details, addresses and logos are made up, and photos are free stock images with their sources listed beside them.

## Sites

### [Ear & Ember Bakehouse](ear-and-ember-bakehouse/)

A single-page site for a neighbourhood bakery, built around one interactive idea: the hero is a wheat ear, and some of its grains open. Hover or run a finger across it to see what's inside, then tap a grain to open that part of the menu.

- Hand-written HTML, CSS and JavaScript in one file, with no framework
- A menu and cart that order over WhatsApp today, and a full checkout that switches on from a config block once a backend exists ([API contract](ear-and-ember-bakehouse/BACKEND.md))
- Showroom picker with directions, a time-aware greeting, and reduced-motion support
- Ordering and contact buttons are in demo mode and show a notice instead of acting
